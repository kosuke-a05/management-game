## 会社の概要
- 金属部品の切削加工（自動車部品・機械部品）。従業員25人。お客さんの図面をもらい、材料を機械で削り、寸法を測って検品し、出荷する。
- 1日の流れ：朝に加工の段取りを決める → 日中は機械を回しながら検品 → 夕方に出荷と翌日の準備。ベテランが機械を持ち、若手とパートが検品や仕上げを手伝う。
- 主な取引先は5社くらい。取引先ごとに「この様式で提出してください」という検査表がある（紙もExcelもある）。
- 検査は、機械のそばではなく検査台でしている。

## 困りごと（山県さんの言葉に近い形で）
1. **検査の記録が、紙とパソコンの二重になっている**
   - 検査員がロットごとに測った寸法を紙の検査表に手書き → 事務の田村さんが、お客さんごとのExcelに後から打ち込む。
   - 打ち込みは1日に検査表20枚前後・1枚5分ほどで、**1日に1時間半〜2時間**（正確には測っていない）。田村さんは週4日勤務で、電話や請求書と兼務。忙しい日は後回しになり、金曜や月末にまとめて打つ。紙のまま残るものもある。
2. **後から記録を探すのに手間がかかる**
   - お客さんからの問い合わせは**月に3〜4回**。探すのに**30分〜1時間以上**かかる時がある。Excelになければ紙のファイルをめくる。「どっちにあるのか、すぐには分からない」。
3. **字が汚れて読めず、読み間違いのおそれがある**
   - 手や紙に油がつく。ビニールカバー越しは書きにくく、外す人もいる。田村さんが「6ですか、0ですか」と聞きに来る。検査員が手を離せないと「たぶん6」で打ち込む。
   - **去年、お客さんに出した記録の数字が1か所違い、後で直した（1回）**。「冷や汗をかいた」。大きな問題にはならなかった。
4. **ヒヤリハットが、その場にいた人しか知らない**
   - 報告の紙の様式はあるが、ほとんど書かれない（忙しい・面倒）。月1回の安全ミーティングで、工場長の大野さんが思い出した範囲を口頭で話す。「気づいたら同じようなことが別の人のところで起きる」。
5. **熟練者の勘が、工場長の大野さん（60歳近く）に集中している**
   - 機械ごとのクセ、材料ごとの注意点、新人に教えるコツ。「一度ちゃんと聞いておかないといけない」と代表も思っている。
6. **取引先の監査の前にあわただしい**
   - 年に1〜2回。直前に記録をかき集める。次は春。

## 理想の状態
- 田村さんの打ち込み時間がなくなり、請求書・見積もり・お客さん対応に回せる。
- 問い合わせを受けたら、**その場で見て答える（探す時間は5分以内）**。
- 読み間違い・推測入力がなくなる。監査の前にあわてない。
- できればヒヤリハットも一緒に残せて、大野さんのコツを若手が見られる（「欲張りかも」）。
- **条件：現場の手間が増えないこと。** 「今の紙より面倒なら、また誰も使わなくなる」。

## 「これができたら一番楽になる」と挙げたもの（一番効く1つの候補）
- **検査の数字が、紙に書かなくても最初から1か所にだけ残ること。**（紙とExcelの二重をなくす）
- ヒヤリハットも大事だが、「書く人が増えないと始まらない」ので、まずは毎日の検査記録。

## これまでに試した対策と、うまくいかなかった理由
1. **検査員が自分でパソコンに入力する方式**（数年前）：パソコンは事務所に1台で、機械のそばから遠い。みんな先に紙に書いてから行くので二重の手間になり、すぐ元に戻った。
2. **タブレットを1台購入**：手が油や切り粉で汚れ、画面が反応しない、手袋だと使いにくい。事務所の棚に置いたまま。
3. **市販の品質管理ソフトの見積もり**：初期費用100万円近く、月額も数万円。「うちの検査表の形に合わせるなら別途」と言われ、見送り。
- 代表の見立て：「結局、現場の手間が増えたから」「現場は油も切り粉もあるので、事務所の道具はそのままでは使えない」「お金の面も大きい話は厳しい」。

## 現場の環境・制約
- 手が油や切り粉で汚れる。手袋のことがある。
- 測る道具は、数字がデジタルで出るものが増えているが、見て紙に手で書き写している。
- 工場の奥は**Wi-Fiが入りにくい**。スマホは全員持っているが、作業中はポケットかロッカーの中。
- **お客さんの図面や寸法には守秘の約束**があり、外に出していい情報かは取引先ごとに決まっている。工場内には**写真撮影禁止の場所**がある。
- **検査表の形は取引先ごとに違う**（主要5社）。1つの形にそろえるのは難しいかもしれない。

## 意思決定・予算・時期
- 最終決定者：山県さん（代表）。ただし**現場に根づくかは工場長の大野さんの納得が大きい**（「大野が使いにくいと言うものは入れられない」）。事務の田村さん（打ち込み担当）の意見も聞きたい。金額が大きい時は、顧問の税理士にも相談する。
- 予算の感覚：**月3万円くらいまでなら試す判断はすぐできる。5万円を超えると少し考える。** 最初に大きな金額がかかるのは厳しい。「まず小さく試して、使えそうなら続ける」形が助かる。
- 時期：春の監査まで、あと数か月。その前に**1か月くらい現場で試したい**。年度末は忙しいので、その前に落ち着かせたい。
- 正式な依頼か：**まだ正式な依頼ではない**。「お願いするかどうかは、ご提案を見てから決める」。

## 検討メモ（カタチ・ミハル）：チェック式の検査表
- サンプル：`customers/yamagata-seiki/prototype/inspection-sheet.html`（印刷でA4・1枚。部品も数字もすべて仮想）。
  - 測った値に近い「丸」を太いペンでぬりつぶす（数字は書かない）。丸の中には、測った値を印刷しておく。→ 6と0の読み間違いがなくなる。
  - 基準を外れた時のために、「小」「大」の破線の丸を付けた。外観・判定・検査員は、チェックだけ。
  - 四隅の黒い四角（傾きを直す）と、ロットのQR（ロット番号）を付け、事務所で撮影して取り込む想定。**読み取りは、まだ試していない。**
- 確認が必要なこと（大野さん・田村さんへの面談、または山県さんに確認）：
  1. 取引先5社のうち、**実測値の記録が必要な項目**と、合否だけでよい項目はどれか。
  2. 検査項目の数・測る個数・公差の幅（丸の数が多くなりすぎないか）。
  3. 取引先ごとに違う**提出用の様式**との関係（社内の記録は1つの形にして、提出用はそこから作る想定）。
  4. ロット番号の付け方と、検査表を印刷する手間（ロットごとにQR付きの紙を出すのは誰か）。
  5. 検査台での撮影が許されるか（事務所で撮影するなら問題なし）。
  6. 紙の素材（油・水・切り粉に強いか）。
- 想定している流れ：検査員が丸をぬりつぶす → 田村さんが事務所で撮影 → 読み取り結果を確認画面で見て、ワンタップで確定 → 1か所の台帳に残る → 後からロット・日付・取引先で探せる／Excelに出せる。お客さんのデータは、端末の中だけに置く（守秘のため）。
